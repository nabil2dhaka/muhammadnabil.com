# Velixo Portfolio - Muhammad Nabil

Premium personal portfolio and design system showcase built with HTML5, CSS3, Bootstrap 5.3, Font Awesome 6, and responsive Bento Grid layout.

## Live Pages
- **Home**: `index.html` - Master bento card with profile, status, social links, contact info, and CTA buttons.
- **Resume**: `resume.html` - Career timeline, education credentials, interactive circular skill rings, neural stack, and partner awards.
- **Projects**: `works.html` - Interactive project showcase with category filtering and interactive modal briefs linking to GitHub.
- **Feed / Blog**: `blog.html` - Engineering logs, insights, featured article, and detailed article modals.
- **Contact**: `contact.html` - Connection card, partnership intake form, and live system metrics.

## Features
- **Bento Grid Architecture**: Clean, modular, responsive cards with subtle glassmorphism and hover elevations.
- **Light / Dark Mode**: Built-in instant theme switcher with local storage persistence.
- **Typography**: Poppins, Archivo, and Space Grotesk via Google Fonts.
- **Icons**: Font Awesome 6 Free.
